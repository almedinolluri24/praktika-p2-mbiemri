
# Praktika Profesionale — Projekti 02

Aplikacion full-stack për porositjen e ushqimit në restorante dhe marrjen e porosive në lokacion.

## Teknologjitë

- Frontend: React
- Backend: Laravel (PHP)
- Database: MySQL
- Version Control: Git dhe GitHub

## Funksionalitetet e planifikuara

- Shfaqja dhe kërkimi i restoranteve.
- Shikimi i menusë dhe produkteve.
- Shporta e porosive.
- Krijimi dhe menaxhimi i porosive.
- Role të ndryshme për përdoruesit dhe stafin.
- Paneli për menaxhimin e restorantit.
- Përgatitja dhe përcjellja e statusit të porosisë.
- Kodi QR për marrjen e porosisë.
- Dokumentacioni dhe testimi i aplikacionit.

## Struktura e projektit

- `frontend/` — aplikacioni React.
- `backend/` — aplikacioni Laravel.
- `README.md` — dokumentacioni i projektit.

## Statusi

Projekti është në fazën fillestare të zhvillimit.

Funksionalitetet do të implementohen dhe testohen gradualisht.
